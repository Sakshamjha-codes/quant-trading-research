# Quant Trading Research

Quantitative finance research project built during CSOT Quant PS'26, IIT Delhi.

## Week 1 — Signal Analysis (AAPL)
Built MA crossover signal. Improved Sharpe from 0.50 → 0.90 vs buy-and-hold.

## Week 2 — ML Return Prediction  
XGBoost + Linear Regression on 1989 trading days. Feature engineering, TimeSeriesSplit.

## Week 3 — Long-Short Portfolio
Market-neutral portfolio across 2167 stocks. Score-weighted momentum signals.

**Tools:** Python, pandas, numpy, yfinance, scikit-learn, XGBoost, matplotlib
